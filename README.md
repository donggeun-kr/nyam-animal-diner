# 냠냠! 동물 식당

26개월 전후 아이를 위한 무료 브라우저 게임. 동물 8종에게 두 가지 음식 중 하나를 골라 먹여 주세요.

## 실행
GitHub Pages: https://donggeun-kr.github.io/nyam-animal-diner/

저장소 Settings → Pages → Deploy from a branch → main → /(root) → Save.
모바일 Chrome에서 사이트를 열고 ⋮ → 홈 화면에 추가를 선택합니다.

- 비용·계정·광고·외부 API 없음
- 5분 기본 놀이, 부모 잠금, 음성 켜기/끄기
- 한국어 TTS는 기기 브라우저에 의존합니다
- 공개 코드에 개인 이름, 녹음, 사진, 토큰 없음
- 놀이 설정만 브라우저 localStorage에 저장합니다

## 작업 규칙
새 기능은 별도 브랜치/PR에서 검증하고 사용자의 승인을 받은 뒤 main에 반영합니다.
새 배포 또는 권한 변경은 별도 승인받습니다.
